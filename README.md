# FC Mobile Hub (fixed floating menu)

This Android project is a simple FC Mobile launcher with a draggable floating FC bubble.
Tap the bubble to open/close the menu. The menu contains an FC Mobile launch shortcut and
a Power Shot training reminder; it does not modify the game, grant currency, or automate shots.

## Build
Open this folder in Android Studio and build with `Build > Build APK(s)`.
The GitHub Actions workflow in `.github/workflows/build.yml` can also build a debug APK.

## GitHub upload
Upload the contents of this folder to the repository root, preserving folder paths.
Do not upload only the workflow file.
